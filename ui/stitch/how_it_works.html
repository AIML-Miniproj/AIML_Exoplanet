Boundary Conditions

Honest Scientific Limitations

Machine learning accelerates candidate identification by 10,000x, but empirical confirmation always demands ground-based observational astrophysics in edge cases.

hourglass_empty
Temporal Constraint

Long-Period Transits (>50 Days)

TESS 27-day sector baselines rarely record multiple transits for long-orbit cold worlds. The model flags monotransits, but true confirmation requires long-baseline Doppler radial velocity tracking.

Requires HARPS / ESPRESSO RV
flare
Host Activity

Extreme M-Dwarf Flaring

Stochastic magnetic reconnection events on active red dwarfs produce asymmetrical flare decay curves. These can mask or mimic shallow sub-Earth transits ($<200$ ppm), requiring spot-modeling manual audits.

Requires Spot-Map Inversion
blur_on
Spatial Resolution

Background Eclipsing Binaries

Because TESS pixels are large (21 arcseconds across), a faint background eclipsing binary within the same pixel aperture can dilute its transit dip, closely masquerading as a true planetary transit.

Requires Adaptive Optics Imaging
